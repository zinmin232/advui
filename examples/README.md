# @advui/examples

Realistic screens built only from `@advui/core`, shared by the docs site
and the Expo app: Login, Dashboard, Admin, Profile settings, Inbox, Product
page, Mobile home and Mobile settings. Metadata is in `src/meta.ts`. A screen
with `fill` in its metadata fills the height it is given and scrolls inside, so
its host gives it a height rather than a scroll view.
