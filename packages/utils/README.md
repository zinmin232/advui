# @adv-ui/utils

Framework-free helpers used by Adv UI.

- **Color:** `parseColor`, `toHex`, `withAlpha`, `toOklch`, `fromOklch` (with
  gamut mapping), `mix`, `adjustLightness`
- **Contrast:** `relativeLuminance`, `contrastRatio`, `readableForeground`,
  `ensureContrast`, `accessibleSolid`
- **Events:** `composeEventHandlers`
